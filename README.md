Las páginas ofrecen instalación PWA, Windows y APK Android, más fuentes y sumas SHA-256 de cada entrega. Todos los releases actuales son prereleases Beta; guarda una copia de tus proyectos antes de probar funciones nuevas.

```powershell
node scripts/workspace.mjs sync
pnpm install --frozen-lockfile
pnpm dev
```

Abre asteoria.code-workspace para trabajar con el núcleo y ocho módulos. Una mejora se implementa una vez y se publica en la versión general y su aplicación. [Entorno y publicación](README-workspace.md) · [Marca, migración y límites](docs/ASTEORIA-BETA.md) · [Atlas](docs/ASTEORIA-ATLAS-0.3.md).
