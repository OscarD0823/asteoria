# Instalar Auralis BETA

Abre https://oscard0823.github.io/auralis/ para la versión general, o la página independiente del programa. Descargas ofrece instalador Windows, APK Android y código de la entrega. Instalar app añade la web como PWA en navegadores compatibles; en iOS usa Compartir → Añadir a pantalla de inicio. Android APK requiere autorizar la instalación desde el navegador o gestor que abre el paquete.

Todos los programas son Beta. Guarda una copia exportada de los proyectos antes de actualizar. Las claves e IDs nativos se conservan para actualizar las instalaciones anteriores y sus perfiles locales. Cada entrega tiene SHA-256 y release prerelease en su propio repositorio. Las actualizaciones descargan archivos del programa; los documentos personales se procesan en el dispositivo.
